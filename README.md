# CyberCheck

Cybersecurity awareness quiz website for employees. Features scenario-based multiple-choice questions (MCQs) and displays a final score and result at the end.

## Run it

```bash
git clone https://github.com/your-username/cybercheck.git
cd cybercheck
```

Open `index.html` directly in your browser.

## Files

* `index.html` - main structure and quiz layout
* `style.css` - styling and responsive design
* `script.js` - quiz questions, scenario logic, and result calculation

## Features

* Scenario-based cybersecurity multiple-choice questions
* Instant result and score summary
* Clean, simple interface

## Notes

* Runs completely in the browser—no server, database, or extra setup needed.

## Requirements

* Any modern web browser (Chrome, Firefox, Edge, Safari)

Built while practicing HTML, CSS, and JavaScript. Works fine.
